# EPC App

The official mobile application for the English Press Club, BITS Pilani. 

This app serves as a centralised hub for campus journalism and news; giving students access to the latest issues, archival media, and interactive campus tools.

## Features
* **The Fine Print:** Keep up with the latest issues of the campus newsletter.
* **Fest Presses:** Read pre-fest interviews and fest issues from APOGEE, BOSM and Oasis.
* **Cactus Flower:** View over four decades of the campus literary magazine archives, and contribute to upcoming editions.
* **Article viewer:** With buttons to go to parent issue, and share article links. Also has an image viewer gallery and PDF viewer.
* **Interactive Campus Map:** A custom 3D map to explore BITS Pilani, Pilani Campus. Hosted on [map.epcbits.com](map.epcbits.com).
* **Social links and the EPC Podcast:** Shortcuts to Instagram, X/Twitter, and Spotify.
* **Coming Soon: In-app Games**

## Tech Stack
* **Framework:** [React Native](https://reactnative.dev/) & [Expo](https://expo.dev/)
* **Routing:** Expo Router (File-based routing)
* **Data Fetching:** TanStack React Query & custom WordPress API integrations
* **UI/Styling:** Custom StyleSheet architecture
